# 李欧丁（Leo Ding）的走路模拟器

一款程序化低多边形风格的 3D Web Game。开场后可选择四个关卡；前三关是带永久成长的短局 Roguelike，失败后从两项能力中选择一项强化，第四关在前三关全部通关后解锁，并保留原版五档步速观察与结尾互动。

- 一碰就死：控制步速和横移，零碰撞坚持 20 秒。
- 一晚就死：在 20 秒内抵达 360 米，碰撞会造成掉速。
- 一哭就死：让 140 米路段持续 20 秒仍未走完，同时保护会被追尾消耗的心情。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端中显示的本地地址。生产构建使用：

```bash
npm run build
npm run preview
```

## 操作

- 前三关按住 `W` / `↑`、`S` / `↓`：连续调节目标速度
- 前三关按住 `A` / `←`、`D` / `→`：左右移动
- 第四关 `W` / `↑`、`S` / `↓`：提高或降低一档速度
- `F`：切换全屏
- `M`：切换声音
- 触屏设备显示左右移动与速度控制按钮

技术栈：Vite、TypeScript、Three.js、Rapier 3D。所有街景、角色和特效均由运行时代码程序化生成，不依赖外部美术资源。

游戏会读取浏览器首选语言：中文浏览器显示中文，其余浏览器显示英文。

## 发布构建

```bash
npm run build:itch
npm run build:pages
```

- `foritch/`：使用相对资源路径，可直接作为 itch.io HTML 游戏上传内容；目录保持未打包状态。
- `docs/`：使用相对资源路径，可作为 GitHub Pages 的发布目录。
